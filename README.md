# Kyiv Nav

Навигатор для Киева и области, который должен работать при глушении GPS.

## Этап 1 (текущий)
Экран «GPS против датчиков»: показывает, когда GPS пропал или врёт,
и пишет CSV-лог поездки (GPS, компас, ускорение, поворот).

## Дальше
- Офлайн-карта Киева и области (скачивается на телефон).
- Маршруты без интернета.
- Определение места по датчикам и привязка к дорогам.

Сборка `.ipa` — GitHub Actions (`.github/workflows/build.yml`), без подписи, для Sideloadly.
